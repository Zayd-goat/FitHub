# FitHub 1.5.0

## New in this update

- Daily supplement reminders with custom supplement names, custom times, quick-add choices, and individual on/off controls.
- PR celebration popup with confetti and the exact improvement achieved.
- PR sharing to the FitHub feed and Android share sheet, with a FitHub deep link and optional public download/landing-page link.
- My Fitness Journey with weekly/monthly workout, PR, lift, cardio, volume, consistency and training-time summaries.
- Safe general observations/recommendations that emphasize consistency, technique and recovery rather than automatic load increases.
- Editable 7-day workout split and a once-per-day "Today: ..." app prompt.
- Adult-only strength Clubs for common tracked lifts, unlocked from recorded PR events.
- Weight unit selection (kg/lb) and distance selection (km/mi), without changing canonical stored workout data.
- Community challenge creation with public/friends/private visibility, friend invitations, progress tracking, creator information and completed/in-progress states.
- Six FitHub visual theme families inspired by the supplied references: FitHub Graphite, Ice Performance, Electric Yellow, Neon Performance, Warm Premium and Ember Orange.
- System/Dark/Light appearance modes, custom accent colour and hide/unhide controls for selected features.
- Existing FitHub 1.4 workout, notification, gym invite, cardio, Food, Friends and PR graph functionality is retained.

## Database

This build is designed for the already-applied FitHub 1.5.0 additive Supabase migration supplied by the user on 14 August 2026. No SQL migration is included in this update package to reduce the chance of accidentally rerunning it.
