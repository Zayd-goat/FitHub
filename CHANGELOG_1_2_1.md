# FitHub 1.2.1

- App icon changed to the selected Bold Strength concept: red F + white dumbbell on a dark icon.
- Theme-aware blue-outline buttons now use the current theme surface instead of a hardcoded white fill.

- Food dashboard redesigned with four daily circular progress indicators: Calories, Protein, Carbs and Fat for adult accounts.

- Food history and existing meal logging retained.
- Friends redesigned around Feed / Following / Challenges tabs.
- Workout feed restyled to look like a social post with avatar, timestamp, title, muscle groups, stats, workout highlights, reactions and inline comments.
- Challenge Join buttons use the theme-aware blue-outline design.
