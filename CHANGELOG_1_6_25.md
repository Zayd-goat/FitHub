# FitHub 1.6.25 Changelog

## Home workout scenes

- Preserved the approved 1.6.24 Home layout and Push Day scene.
- Added dedicated transparent equipment scenes for Pull, Legs, Upper Body, Full Body, Cardio, Shoulders, Arms, Core and Recovery.
- Removed anatomy artwork from the Home workout-plan rotation while leaving exercise guidance assets unchanged.
- Added source and PNG audits for every Home equipment asset.

## Community Challenges

- Rebuilt the Community header and top-level Challenges/Clubs navigation.
- Added Active, Invites and Completed summaries.
- Added Explore, Active, Invites and Completed filters.
- Added a three-step challenge creator for details, goal and invitations.
- Improved creator attribution, visibility, difficulty, time remaining, member counts and progress presentation.
- Preserved join, accept, decline, workout-history progress and completion behaviour.

## Clubs

- Added full-width milestone cards with Your Best and Club Mark comparison.
- Improved active-member counts, earned dates, refresh, error and empty states.
- Added a concise How Clubs Work explanation.
- Preserved historical backfill, normalized exercise matching, kg/lb display and highest-active-club behaviour.
- Preserved the under-18 load-based Clubs restriction.

## Release

- Version updated to `1.6.25`.
- Android version code updated to `35`.
- iOS build number updated to `35`.
- GitHub APK artifact updated to `FitHub-1.6.25-APK`.
- No SQL migration, Edge Function, secret or cron change is required.
