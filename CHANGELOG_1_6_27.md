# FitHub 1.6.27 Changelog

## Home interface

- Added transparent, dimensional mini-scenes to `Your Week` for workouts and active minutes.
- Added matching Journey, Nutrition, Supplements, Community Challenges and Run Metrics artwork.
- Increased Quick Access visual hierarchy while retaining the existing routes and full-width Run Metrics destination.
- Kept the live seven-day calendar, completed-day markers, workout count and active minutes connected to workout history.

## Food interface

- Added matching diary-planning, Search, Scan, Recent, Saved Meals, meal and hydration mini-scenes.
- Kept labels, dates, progress and logged-meal state as native UI rather than embedding them in screenshots.
- Preserved Search, Scan, Recent, Saved Meals, meal expansion, add/remove, saved-meal and water handlers.
- Preserved all younger-account nutrition safeguards.

## Navigation and build fix

- Added five original monoline navigation components in `src/components/FitHubNavIcons.tsx`.
- Added a short cyan active-tab indicator and refined the familiar raised Train control.
- Replaced the unsupported `StyleSheet.absoluteFillObject` spread with explicit absolute bounds.
