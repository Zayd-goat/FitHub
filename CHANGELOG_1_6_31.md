# FitHub 1.6.31 changelog

## FitHub popups

- Replaced the old native alert presentation with one theme-aware FitHub action sheet across the app.
- Added a large close control and a clear dismissal hint.
- Added tap-outside dismissal and Android hardware-Back dismissal.
- Kept long action lists scrollable so Android no longer hides later actions.
- Preserved default, cancel and destructive action behavior.

## Post controls

- Post controls now show Edit caption or photo, like-count visibility, comment-count visibility, Delete post and Cancel together.
- Delete post remains protected by a second confirmation.
- Deletion removes the shared post, comments, reactions and its shared photo while preserving the private completed workout.
- Deletion remains scoped to the signed-in post owner.

## You

- Replaced the previous flat card illustrations with seven original realistic transparent assets.
- Updated Journey, Supplements, Workout split, Gym together, Customize FitHub, Weekly split and Clubs.
- Increased the Quick access card artwork area to match the approved visual hierarchy.
- Kept all existing routes, hiding preferences, themes, editing actions and younger-account safeguards.
- The Supplements artwork is generic and unbranded, with no product, performance or dosage claim.
