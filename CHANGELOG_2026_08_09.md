# FitHub 1.2.0 — requested update

## Onboarding & profile
- Sequential onboarding: one question per screen.
- Top progress bar.
- Editable age, experience, activity, gender, height/unit, weight/unit, goal and weekly training target from Profile.

## Training
- Exercise tap opens configuration immediately.
- Strength: sets, weight and reps.
- Cardio: duration/distance and load when appropriate.
- Add another exercise or start workout from exercise setup.
- Live set table with editable values and completion checks.
- Completed exercises fade in the active-workout list.
- Expanded cardio library and cardio visuals/icons.

## Progress
- Working View all navigation.
- Progress/achievement page.
- Login/workout/meal badges.
- Adult-only nutrition-target badges.
- PR tracking with selectable lifts and PR history.

## Food
- White add buttons with blue outlines.
- Daily target progress bars and macro graphs for adult accounts.
- 90-day food/meal history.
- Under-18 meal journal remains free of calorie/macro targets.

## Home
- Maximum 3 recent workouts on Home.
- View More opens 15 most recent workouts.
- Home recent display clears after 7 inactive days without deleting saved history.
- Daily Volume and adult estimated Calories Burned reset with the local day.

## Friends
- Rich workout post cards with session stats.
- Comments and quick supportive replies.
- Challenge Join buttons use the white/blue-outline treatment.

## Visual / app shell
- New selected Concept #1 FitHub icon direction.
- New minimal bottom navigation icons.
- Main app hides the phone status bar for a full-screen presentation.
- Version 1.2.0 / Android versionCode 3.
